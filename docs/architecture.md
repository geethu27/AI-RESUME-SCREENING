## 2. Multi-Factor Candidate Screening Algorithm

Smart Screen AI replaces black-box scoring with a transparent, grounded 4-factor formula:

$$\text{Final Score} = (0.40 \times \text{Semantic}) + (0.35 \times \text{Skills}) + (0.15 \times \text{Experience}) + (0.10 \times \text{Education})$$

### Factor Breakdown:

1. **Semantic Similarity (40% Weight):**
   - Generated by passing the full resume and job description through `sentence-transformers/all-MiniLM-L6-v2`.
   - Embeddings are L2-normalized so that inner product in FAISS corresponds directly to cosine similarity:
     $$\text{Cosine Similarity} = \frac{\mathbf{u} \cdot \mathbf{v}}{\|\mathbf{u}\|_2 \|\mathbf{v}\|_2}$$
   - Normalized to a $0 - 100\%$ scale.

2. **Skill Match Score (35% Weight):**
   - Uses exact matching and alias/synonym mapping (e.g. `JS` $\rightarrow$ `JavaScript`, `K8s` $\rightarrow$ `Kubernetes`, `Py` $\rightarrow$ `Python`, `Postgres` $\rightarrow$ `PostgreSQL`).
   - Formula:
     $$\text{Skill Match Score} = \frac{|\text{Matched Skills}|}{|\text{Required Skills}|} \times 100$$
   - Cites matched and missing skills explicitly.

3. **Experience Match Score (15% Weight):**
   - Extracts candidate years of experience via regex patterns (`r'(\d+)\+?\s*(?:years?|yrs?)'`).
   - Parses job requirements (e.g., `Fresher` $\rightarrow$ 0 yrs, `3+ years` $\rightarrow$ 3 yrs).
   - If candidate experience $\ge$ required: **100%**.
   - If candidate experience $<$ required: Pro-rated score $\max(30\%, \frac{\text{Candidate Exp}}{\text{Required Exp}} \times 100\%)$.

4. **Education Match Score (10% Weight):**
   - Evaluates academic credentials against job requirements using an educational hierarchy:
     $$\text{Doctorate} (4) \ge \text{Master's} (3) \ge \text{Bachelor's} (2) \ge \text{Diploma} (1)$$
   - Full points (100%) if candidate tier $\ge$ job requirement.
   - Partial points (60-80%) for adjacent tiers.

### Recommendation Tiers:
- **$\ge 80\%$**: Strong Match
- **$65\% - 79\%$**: Recommended
- **$50\% - 64\%$**: Review Further
- **$< 50\%$**: Not Recommended

## 3. Retrieval-Augmented Generation (RAG) & Anti-Hallucination Guardrails

The Recruiter AI Assistant features strict anti-hallucination guardrails:

1. **Vector Retrieval**:
   - FAISS retrieves the top-$K$ most relevant resume and job chunks filtered by `candidate_id` and/or `job_id`.
2. **Context Construction**:
   - Extracted candidate text and job criteria are compiled into a structured Markdown prompt.
3. **Anti-Hallucination Rules**:
   - LLM is instructed: *"Answer using ONLY facts directly stated in the provided context. If the question asks for information not present (e.g., favorite food, personal opinions, unmentioned salaries), explicitly state that it is not available in the records."*
4. **Local Fallback Engine**:
   - Includes a deterministic `LocalGroundedLLMProvider` using word-boundary matching and structured information extraction that works 100% locally with zero external API dependencies or costs.
